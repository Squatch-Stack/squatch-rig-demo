# Squatch Rig public demo

[Open the browser demo](https://squatch-stack.github.io/squatch-rig-demo/) · [Light](docs/screens/rig-light.png) · [Dark](docs/screens/rig-dark.png) · [Phone](docs/screens/rig-phone.png)

Browser guitar rig with four playable quick sounds, selectable light/dark themes and two device skins. The bundled NAM Core example models are MIT licensed; the playable DI loops carry their credits and licenses in `assets/d8e5eba8d1c1/audio/loops/index.json` and in the app. The DI test excerpt is from the “Five guitar dataset” by Eduard Vergés Franch (2021), [Zenodo 10.5281/zenodo.4988354](https://doi.org/10.5281/zenodo.4988354), trimmed, resampled, and normalized under CC BY 4.0. Source code is MIT licensed. This repository holds the sources of a static site that was exported from the development tree with `tools/export-public.mjs`. The NAM engine (`nam.wasm`) is never committed: GitHub Actions builds it from pinned public sources (`wasm-src/PINS`: stock upstream NAM Core, and a second, opt-in `nam-experimental.wasm` that adds `wasm-src/experimental-fast.patch`; a pinned Emscripten), scans the whole site, attests the build and deploys it to Pages. No private captures are included.
