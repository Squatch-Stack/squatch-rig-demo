# Squatch Rig public demo

Browser guitar rig with four playable quick sounds, selectable light/dark themes and two device skins. The bundled NAM Core example models are MIT licensed; the playable DI loops carry their credits and licenses in `audio/loops/index.json` and in the app. `audio/di-loop.wav` is a CC BY 4.0 test excerpt from the “Five guitar dataset” by Eduard Vergés Franch (2021), [Zenodo 10.5281/zenodo.4988354](https://doi.org/10.5281/zenodo.4988354), trimmed, resampled, and normalized. Source code is MIT licensed. This static artifact was exported from the private development tree with `tools/export-public.mjs`. No private captures are included.
